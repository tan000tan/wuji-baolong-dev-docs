## 🧱 游戏概览

```text
160×160×64 体素世界（种子随机）
├─ 生物群系：草原 / 森林 / 沙漠 / 雪地 / 山地 / 湖泊 / 沙滩
├─ 地下世界：洞穴 · 煤矿 · 铁矿
├─ 生存系统：生命值 · 饥饿值 · 昼夜循环 · 天气（晴/雨/雪）
├─ 制作系统：木 / 石 / 铁工具 · 合成台
├─ 战斗系统：僵尸等怪物 · 近战武器
└─ 控制：虚拟摇杆 + 触摸视角 + MC PE 手势（长按连挖等）
```

- 引擎：Unity 2022.3.62f3c1 LTS / URP / IL2CPP / GLES3
- 平台：Android 7.0+（ARM64），包名 `com.wbs.dragonwarrior`
- Final 1.0：versionCode 9，21.4 MB
